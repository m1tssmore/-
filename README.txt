漢字道場 / KANJI DOJO

Запуск: откройте index.html (лучше через любой локальный сервер или хостинг).

Структура
  index.html        разметка
  css/style.css     стили и обе темы (светлая / тёмная)
  js/theme.js       переключатель темы + падающие лепестки
  js/strokes.js     порядок черт: загрузка данных и анимация рисования
  js/app.js         вся логика приложения (кандзи, кана, слова, тесты)
  js/grammar.js     вкладка «Правила»: грамматика, частые глаголы, плавные блоки
  js/lessons.js     раздел «Уроки»: грамматика по урокам 1–25 (порядок «Минна но нихонго I»)
  assets/           фоны тем (theme-light.jpg, theme-dark.jpg)

Темы
  Кнопка ☀ / ☾ в шапке. Выбор запоминается. Светлая — розовые лепестки,
  тёмная — белые.

Подсказка (порядок черт)
  В окне знака кнопка «Подсказка» рисует знак черта за чертой с номерами.
  После показа остаётся бледный контур для обводки; «Скрыть» убирает его.
  Данные берутся из KanjiVG: при первом показе знака нужен интернет,
  потом знак сохраняется на устройстве.
  Для полностью офлайн-работы положите файлы KanjiVG (например 06728.svg)
  в папку data/kanjivg/ — они проверяются первыми.

Несколько знаков (например 日本)
  В поле «Иероглиф или слово» можно ввести до 6 знаков. В окне знака для
  каждого появится своя вкладка: у каждого знака своё поле для рисования и
  своя подсказка с порядком черт. Рисунок на вкладке сохраняется при
  переключении. То же работает в тесте «Значение → нарисуй знак».

Вкладка «Правила» (文)
  Три раздела: «Правила» (чтение и письмо), «Грамматика» (устройство языка,
  частицы, прилагательные, глаголы и их формы, числительные, наречия,
  местоимения) и «Глаголы» (30 частых глаголов; кнопка ＋ добавляет их во «Слова»).
  Структура грамматики составлена по статье nihon-go.ru, тексты и примеры
  написаны заново. Чтобы добавить или изменить текст, правьте массив GR в js/grammar.js.

Установка как приложения (PWA)
  Открой сайт в Chrome на телефоне по адресу http(s) или localhost (например,
  через локальный сервер) → меню ⋮ → «Установить приложение» / «Добавить на
  главный экран». Появится значок 桜, приложение откроется без адресной строки
  и после первого запуска работает без интернета (sw.js, manifest.webmanifest, icons/).
  При открытии файла напрямую (file://) офлайн-кэш не включается.

Раздел «Уроки»
  25 уроков в порядке учебника «Минна но нихонго I» (по оглавлению тома
  «Перевод и грамматический комментарий»): для каждой грамматической темы
  схема, объяснение и примеры с furigana, плюс вводный урок с приветствиями,
  таблицы дней недели, дат, времени, форм глагола и сводка частиц по урокам.
  Объяснения и примеры написаны заново, слова уроков не включены.
  Чтобы править текст, открой массив L в js/lessons.js (запись 漢字{かんじ}
  превращается в иероглифы с подписью чтения).

Плавные переходы
  Окно знака выезжает снизу с размытием фона, блоки раскрываются по высоте,
  вкладки и карточки появляются по очереди. При включённом в системе
  «уменьшении движения» анимации отключаются.
